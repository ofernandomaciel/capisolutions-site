## Convenção de trabalho entre sprints

Cada nova sprint deve começar em um chat/tarefa separado para preservar contexto, decisões e rastreabilidade. Ao encerrar uma sprint e preparar a seguinte, o assistente deve:

1. avisar que é o momento de abrir um novo chat;
2. oferecer-se para criar a nova tarefa quando o escopo inicial estiver definido;
3. preparar um handoff curto com decisões, pendências, fontes e primeiro objetivo da nova sprint;
4. manter neste chat apenas o trabalho pertencente à Sprint 01.
